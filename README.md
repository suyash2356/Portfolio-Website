# 🌐 Personal Portfolio Website

A simple and responsive **portfolio website** built using only **HTML, CSS, and JavaScript**.  
This project is designed to showcase personal details, skills, projects, and contact information in a clean and professional way.

---

## ✨ Features
- 📱 Fully responsive design (works on desktop and mobile)
- 🎨 Clean and modern UI
- 📂 Sections for **About Me, Skills, Projects, and Contact**
- ⚡ Lightweight — no frameworks, just pure HTML, CSS, and JavaScript

---

## 🛠️ Technologies Used
- **HTML5** – structure
- **CSS3** – styling and responsive layout
- **JavaScript (ES6)** – interactivity
